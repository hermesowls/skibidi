## Genuine prior fixtures

`fixtures/stage2_prior_cards/` contains byte-for-byte preserved prior evaluator and alert producer code, not reconstructed approximations. `provenance.json` records SHA256 hashes and source archive provenance. The copies were compared with both the original pre-card archive and the independent review's copies before promotion. The loader verifies hashes each time and refuses loading without the guarded sandbox marker. The fixtures are loaded exclusively by tests; production imports were not changed.

The legacy regression runs actual prior evaluators/renderers through actual producers for registered schema-1 finite-cap and schema-2 uncapped policies, then reevaluates through the current producer. It asserts unchanged candidate, decision, queue identity and card bytes, with retry resume and full authorization/identity rejection invariants. SQL saturation observes real SQLite result sets and verifies read-only deterministic bounded history. Robustness checks use authenticated history and actual renderer calls, retain valid neighbors, and distinguish explicit null (Unlimited) from absent/invalid cap (Unknown).

Only display validation is repaired here. This suite does not confer stage acceptance, live qualification, deployment, publication or execution authority. Use a separate independent narrow review before closeout.
