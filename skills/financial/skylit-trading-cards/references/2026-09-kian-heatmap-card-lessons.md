# 2026-09 Kian Heatmap Card Lessons

Session-specific refinements from repeated Skylit Heatseeker GEX/VEX reads.

## User Corrections Captured

- No Markdown bold asterisks in routine trading cards; user wants clean copy/paste text.
- `My Trade Opinion` is mandatory and must appear immediately after `Bias`, not near the bottom.
- Scan further expirations for King Nodes and major clusters, not only front expiry; label later-expiry nodes as weekly/swing context.
- Verify ticker from the screenshot header. If the user label conflicts with the screenshot, call out the mismatch and correct the card.

## Card Behavior That Worked

Use direct conditional logic:

```text
Hold X -> target Y
Reclaim X -> target Y/Z
Reject X -> fade to Y
Lose X -> downside opens to Z
```

King Nodes are destination/pin/magnet zones, not entries. If spot is on or near a King Node, call it a pin/decision/chop zone. Directional bias requires support hold, reclaim, rejection, or breakdown confirmation.
