# Kian Heatmap Session Rules

Session-specific lessons captured from repeated Skylit Heatseeker / ATLAS reads.

## User Preferences

Kian wants concise, actionable trader cards, not theory-heavy output. The final answer should include a direct bias and a trade opinion, with clean conditional logic.

Preferred language:

- “Hold/reclaim X → target Y.”
- “Reject X → fade to Y.”
- “Lose X → downside opens to Z.”
- “Bullish above X / bearish below Y / neutral inside range.”

## Critical Correction Learned

Kian corrected the PLTR read when price was sitting on a King Node around $177.50 with a massive negative wall at $180. The correct interpretation was neutral/pinned, not long-and-strong. This correction should govern future reads.

Rule: **King Node = destination/magnet/pin, not entry.** Directional bias requires hold/reclaim/loss confirmation and awareness of nearby walls.

## ATLAS / Kian Market Sentiment

Kian uses ATLAS/TRINITY as market context before ticker trades. For ticker reads, market support matters: SPXW/SPY/QQQ reclaim levels and VIX behavior can raise or lower confidence.

Kian Market Sentiment is the final confluence layer before entering a new position:

1. Heatmap levels
2. Flow confirmation
3. ATLAS / index context
4. Kian Market Sentiment
5. New position decision

## Telegram Completeness

The user asked “where is the rest of the message” after a long heatmap card likely got clipped. Keep future cards shorter and complete. If a response is clipped, resend the full concise card immediately with the missing content, not a plan or apology-only answer.
